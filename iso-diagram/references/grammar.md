# Grammar rules

Default grammar rules for this skill.

- Be clear and concise; every sentence should carry essential information.
- Headings should be kept to 5 words or fewer, and should not contain contractions. Only capitalize the first word and abbreviations within headings.
- Use one space after a period
- Colons introduce a list, series or example, and only after a complete sentence. Never put one between a verb and its object.

- Use the Oxford comma

*Yes*

```
Bring me a pencil, pen, and a notebook.
```

*No*

```
Bring me a pencil, pen and a notebook.
```


- Apply standard US English capitalization rules, or language-specific rules, if different.

*Yes*

```
This diagram includes AWS regions and VPCs.
```

*No*

```
This diagram includes AWS Regions and VPCs.
```
